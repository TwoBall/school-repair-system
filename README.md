# 学校总务报修管理系统（本地 Docker 增强版）

基于 **Node.js (Express) + SQLite** 构建的轻量级、高可用学校/企业总务报修系统。已彻底摆脱对外部云开发环境（如腾讯云 CloudBase）的依赖，实现**单容器一键离线部署**、**数据与照片本地持久化**，并大幅升级了多项企业级管理功能。

---

## ✨ 核心特性与新增功能

### 1. 🐳 本地 Docker 部署与数据持久化
- **轻量独立**：内嵌高可靠 SQLite 引擎，无需额外搭建 MySQL 或 MongoDB 数据库。
- **持久化保存**：通过 Docker Volume 挂载 `./data`（数据库）与 `./uploads`（工单现场照片），升级或重启容器数据绝不丢失。
- **真实文件上传**：告别原版 base64 存储大小限制，支持多张高保真现场照片/完工照片上传与大图预览。

### 2. ⚙️ 基础数据可视化管理（告别硬编码）
总务处管理员登录后，在**「基础配置」**专区可进行全可视化维护：
- **👨‍🔧 维修师傅管理**：新增/编辑维修师傅姓名、擅长领域、联系电话、工号与独立登录密码，支持一键重置密码与账号启用/停用。
- **🏢 报修楼栋管理**：可视化增删改校区楼栋区域，支持自定义排序与显示隐藏。
- **🏷️ 故障分类管理**：可视化维护报修类别（水电照明、空调风扇、网络多媒体等）。
- **🔒 口令与设置管理**：支持在线修改总务处后台口令，免去修改配置文件的繁琐操作。

### 3. 🔔 企微 / 钉钉 / 飞书 机器人通知 (Webhook)
在「基础配置」中可一键配置工作群机器人 Webhook：
- **新报修提醒**：师生提交报修即刻推送到总务处工作群，包含单号、地点、紧急度和故障描述。
- **派工通知**：指派师傅后即刻通知到责任人。
- **维修进度与完工提醒**：师傅接单、完工及用户验收评价自动同步工作动态。
- **加急催单预警**：报修人发起催单时，以红色加急卡片推送给值班管理群。
- **一键测试**：后台提供「测试 Webhook 发送」按钮，配置后立即验证连通性。

### 4. 👷 维修师傅独立账号与权限体系
- 摒弃了原版“单一口令+随意切换师傅姓名”的模式。
- 每位师傅拥有独立的工号/手机号和登录密码，登录后生成加密会话 Token。
- 师傅只能接单和操作指派给自己的工单，防止串单、冒领与误操作。
- 师傅端支持自主修改登录密码。

### 5. ⚡ 工单催单与现场留言沟通板
- **加急催单**：报修人在查单详情中可点击「加急催单」（内置 10 分钟防频刷机制），记录自动计入工单时间轴，并触发高优先级群机器人告警。
- **现场沟通留言**：工单详情内置留言板，报修人、总务处与维修师傅可在工单下实时留言互动（如预约上门时间、告知配件情况），时间轴清晰可追溯。

### 6. 🖨️ 工单打印（派工单 / 验收单）与 Excel 报表导出增强
- **一键打印派工单**：在工单详情中点击「打印派工单」，自动调出符合 A4 标准格式的正式派工单样式，包含报修信息、故障描述、维修记录、双方验收确认及盖章签字栏。
- **Excel / CSV 报表导出**：支持根据当前搜索、楼栋、分类、紧急度及状态筛选条件，一键导出带 UTF-8 BOM 的 CSV 报表，用 Excel / WPS 打开不乱码。

### 7. ⏱️ SLA 超时预警与监控
- 可自定义**待受理超时**、**派工未接单超时**、**接单未完工超时**的小时阈值（紧急单自动缩短时限）。
- 超时工单在列表与卡片中具有醒目的红色脉冲标签与超期时长显示。
- 数据看板专设「超时工单」KPI 卡片，点击即可一键过滤所有超期滞留工单。

## 🚀 快速启动指南

### 方式一：使用 Docker 一键启动（推荐）

#### 1. 前提条件
已在服务器或本机安装 [Docker](https://docs.docker.com/get-docker/) 及 Docker Compose。

#### 2. 一键启动
在项目根目录下打开命令行终端执行：
```bash
# 使用 Docker Compose 构建并启动容器（后台运行）
docker compose up -d --build
```

启动完成后，打开浏览器访问：
👉 **http://localhost:3000** （如部署在服务器，请将 localhost 替换为服务器 IP）

#### 3. 停止与查看日志
```bash
# 查看实时运行日志
docker compose logs -f

# 停止容器
docker compose down
```

---

### 方式二：直接在宿主机本地运行 (Node.js)

如果您本机未安装 Docker，也可直接使用 Node.js 启动：

#### 1. 前提条件
安装 Node.js 18 / 20 / 22+ 运行环境。

#### 2. 安装依赖并启动
```bash
# 1. 安装项目依赖
npm install

# 2. 启动服务
npm start
```
控制台输出：
```text
===============================================
🚀 学校总务报修管理系统 (本地Docker版) 已启动
📡 服务监听地址: http://0.0.0.0:3000
📁 数据目录: ./data
🖼️ 图片目录: ./uploads
===============================================
```
直接在浏览器打开：**http://localhost:3000** 即可使用。

## 💾 数据备份与迁移

由于所有工单数据和上传的现场照片均以独立文件形式保存在项目根目录下：
- **工单与配置数据**：`./data/repair.db`
- **现场与完工图片**：`./uploads/`

**备份只需执行**：
```bash
# 备份数据文件
tar -czvf repair_backup_$(date +%Y%m%d).tar.gz data uploads
```
**恢复数据**：只需将备份文件解压到新的服务器对应目录下，启动 Docker 容器即可无缝恢复所有历史工单、照片与人员配置！
